# Screenshot capture log

All captures use Playwright with reduced motion and cookie banners dismissed.
Blocked paths: login, dashboard, admin, account, track, api. A bare public sign in screen is captured only where a shot sets allowSignInScreen.
`npm run screenshots` rewrites this file with the latest run only, so merge older entries back in by hand.

# Brand assets

Generated from the owner's logo by `node scripts/build-brand-assets.mjs <logo.png>`.

- logo.png: navy wordmark with the orange X, transparent background, for light surfaces.
- logo-on-dark.png: the same mark with the letters in off white, for navy surfaces.
- mark.png and mark-on-dark.png: the X alone.
- email-logo.png: logo-on-dark.png at 256px wide (shown at 128px) for the navy header of every email. Emails load it from the live site, so keep the path stable.
- src/app/icon.png, apple-icon.png and opengraph-image.png are picked up by Next.js automatically.

Measured colours. Navy #05035a, orange #fc8f2d.
